# 베팅 접수 성능 검증 상태

`sportsbook-v2.0.0` hardening 구현에는 아직 채택된 처리량 결과가 없습니다. 따라서
현재 릴리스의 RPS, 지연 백분위 또는 운영 수용량을 이 파일에서 주장하지 않습니다.

현재 동시성 harness는 같은 `Idempotency-Key` 100건이 하나의 bet, 하나의 wallet
차감, 하나의 bet outbox 효과로 수렴하는지 검증합니다. 새 성능 결과는 이 cardinality
검사까지 통과하고 소스 SHA, shared 계약, 자원과 측정 조건을 함께 기록해야 합니다.

`results/2026-05-29/`의 원본은 복구 가능한 상태 머신 도입 전 구현의 역사 자료이며
현재 릴리스의 성능 또는 멱등성 증거로 사용하지 않습니다.
